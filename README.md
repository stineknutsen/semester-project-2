# Auctioneer

![Project Screenshot](./images/screenshot.png)

## Description

Auctioneer is an auctions website built for a fictional client as Semester Project 2 for Noroff Front-end development. It is a platform where people can register a user, and buy and sell their items. It is live at https://semester-project-2-auctioneer.netlify.app/

## Pages

- Register page
- Log in page
- Home page / feed page
- Single listing page
- Profile page

## Features

- Register a user
- Log in and log out
- View your own profile
- View your own listings, bids and winnings
- Create, update and delete listings
- View a feed of listings
- Search for listings title, description, tags
- Sort listings by newest or oldest
- View a single listing
- Bid on a listing

## Technologies used

- HTML: structure
- Tailwind CSS: layout, styling and responsiveness
- JavaScript: functionality and content
- Noroff API

## Running the project

### Running the project locally

1. Clone this repository

```bash
git clone https://github.com/stineknutsen/semester-project-2
```

2. Install dependencies:

```bash
npm install
```

3. Use Live Server to open index.html in your browser

4. Run script:

```bash
npm run build
```
